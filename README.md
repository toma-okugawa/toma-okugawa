## Featured

### [SD-Retinex](https://github.com/toma-okugawa/sd-retinex)

A training-free, CPU-oriented low-light method: a stable real-axis kernel (the sigmoid derivative) and a bounded sigmoid tone map. On LOL (eval15) it reaches 16.47 dB PSNR at 18.4 ms per image (54 FPS) on a laptop CPU, ahead of the classical Retinex methods and the zero-reference deep methods it was compared with.
